# 2K Archive — Lucian vs Josiah

Static, read-only mirror of the 2K bracket tracker record (Lucian vs Josiah, NBA 2K head-to-head).
Single self-contained `index.html` (logos inlined) so every push to `main` auto-deploys on Vercel.

Source of truth for results is the live Muse tracker. To update after a game:
edit the data in `~/workspace/2k-archive-vercel/build.py`, run `python3 build.py`, push `index.html`.
